# Project content sources

Reviewed 2026-10-23.

- Helivision: https://github.com/Arnavmangarapu/helivision/blob/main/README.md . The documented final prototype is camera/vision based, with TensorFlow Lite, Raspberry Pi, Picamera2, LED/OLED, audio and haptic outputs. Experimental radar/ultrasonic work is not shown as final hardware. The illustration is a front-view conceptual reconstruction, not a hardware photograph.
- StreamWatch: https://github.com/Arnavmangarapu/streamwatch/blob/main/README.md . The repository describes React/Vite/Tailwind, FastAPI, MongoDB, Gemini natural-language query generation and validation, JWT/OTP/RBAC, Prometheus and Grafana. This corrects the earlier résumé-only Node/Express summary. The interactive view uses illustrative data and makes no live system connection.
- SRDC: https://github.com/Arnavmangarapu/SRDC-Ransomware-Detection . Returned 404 during review. Its description and semantic-processing diagram are based on the supplied résumé. No unverified benchmark results or dataset sizes are presented.
