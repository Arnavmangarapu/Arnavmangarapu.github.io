StreamWatch

A secure MongoDB workspace for natural-language queries and system monitoring.

The challenge

StreamWatch combines a natural-language database interface with account security and operational monitoring. Users can turn an English question into a validated MongoDB query and inspect results in the web interface.

From question to query

  • A React and Vite interface sends a natural-language question to a FastAPI backend.
  • Gemini generates a MongoDB query. Security and schema validation check collections, fields and allowed operations before read-only execution.
  • Results and query history return to the interface. Prometheus separately scrapes backend /metrics, and Grafana powers the System Vitals dashboard.

Building the application

The repository uses React, Vite and Tailwind for the frontend, FastAPI for the backend, and Motor/PyMongo for MongoDB access. Account features include JWT authentication, OTP email verification, password reset and role-based access. The application includes query history, an admin dashboard and sensor-data CRUD operations. Query protections include destructive-operator blocking, collection and field allowlists, regex checks and read-only aggregation.
