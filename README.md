# Sree Arnav — Portfolio

Live website: https://arnavmangarapu.github.io/

This is a static website, served from the root of the main branch using GitHub Pages. No build or installation is required.

## Update the website

Edit `content.js` to add or update projects and skills. Edit `index.html` to update profile, experience and contact details. Upload replacement artwork alongside these files, then use its filename in the project image field.

Commit changes to `main`; GitHub Pages republishes automatically. Monitor deployment in the Actions tab. Hosting is configured in Settings → Pages → Deploy from a branch → main → / (root).

## Preview locally

Run `python3 -m http.server 4173` in this folder, then visit http://localhost:4173.

## Motion and licenses

The Motion switch remembers the visitor’s choice and skips animation libraries when off. Animation libraries and license notices are bundled alongside the site. See ANIMATION-SOURCES.md for credits and license information.

Missing work history and project links remain placeholders. The résumé PDF and contact links are public as part of this portfolio.
