The challenge

SRDC explores behaviour-based ransomware detection. The project translates system activity into semantic text so that a language model can learn representations of behaviour, rather than treating each log event in isolation.

From logs to representation

  • Windows API, registry, file-system and behavioural logs supply the input signals.
  • Python preprocessing and feature engineering convert those logs into semantic text.
  • GPT-2 and Hugging Face Transformers are used for fine-tuning and semantic representations for classification.
